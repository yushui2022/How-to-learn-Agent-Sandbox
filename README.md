# 从 0 到 1 学 Agent 沙箱

> 以腾讯 CubeSandbox 为主案例，系统讲清 Agent 沙箱的隔离、供给、治理、并发、编排与源码机制。

本仓库只提交本 README 与 `文章内容/`。主线章节负责逐步建立完整知识体系；扩展研究放在主线之后，用来回看、深化和推演前文问题。
